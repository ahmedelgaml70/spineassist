# Model sources and licensing notes

## Primary candidate

Repository: `hpfrei/body-anatomy-3d-viewer`  
File: `public/body.glb`  
Purpose: complete anatomy model suitable for browser/Three.js use.

The source project states that its model data comes from Z-Anatomy and is licensed under CC BY-SA 4.0. Verify and preserve attribution before publishing/distributing final teaching materials.
